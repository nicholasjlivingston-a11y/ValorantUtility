# ValorantUtility (Valosaber)

Sabermetric-style statistics for Valorant, built from parsed replay (.vrf) data.

- `vault/` Obsidian vault. Start with `vault/00 START HERE.md`.
- `parser/` metrics, shard ingest and page-build scripts.
