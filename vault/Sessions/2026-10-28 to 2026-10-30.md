# Sessions 2026-10-28 to 2026-10-30

A reconstruction of how the project got here, in order, so a new chat understands why things are the way they are.

1. **Access.** The user asked Claude to access Google Drive. Metadata was readable; a 159 MB replay zip was not (10 MB download limit). The user attached the parsed tables instead.
2. **First parse.** The `valorant-vrf` skill's table builder crashed on this replay. Cause: Swiftplay uses a different PlayerState class and swaps sides after round index 3, not 12. A patched copy fixed both ([[Replay Data Guide]]).
3. **Names.** Agent names are internal codenames. Three were confirmed from the skill. The rest were resolved through sources, the replay manifest's agent IDs and kit evidence ([[Agents]]). The user's guesses were checked rather than trusted; Sequoia turned out to be Iso, not Tejo.
4. **Data options and the lookup.** The user asked how to make agent, map and ability names correct. Allowing `valorant-api.com` would do it; it stayed blocked, so a lookup file with evidence per row was built ([[ADR-005 Names only when confirmed]]).
5. **Sabermetrics for Valorant.** The user asked for the same depth as baseball sabermetrics. Claude researched the concepts ([[07 Sabermetrics Notes]]) and built Valosaber from the per-player combat reports: WPA, leverage, indexes, trades, clutch, head-to-head.
6. **Reconciliation.** Rebuilt kills matched the death log (34 of 34, 9 ms). Owners of the combat reports were resolved by damage reciprocity ([[ADR-001 Owner resolution by damage reciprocity]]).
7. **What the data needs.** Claude listed what the pipeline must add. Two briefs for a coding agent were written ([[Coding Agent Brief]]).
8. **Utility.** Stage 1 utility credit was built with adjustable weights; Stage 2 and 3 were planned ([[Utility Credit]]).
9. **Size limits.** The shard and ingest design was built and tested ([[Data Pipeline]]). A join bug that dropped three players from the position data was found and fixed.
10. **Memory.** This vault was built so a new chat can pick up from [[00 START HERE]].
